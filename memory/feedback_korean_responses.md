사용자에게 보내는 답변은 **항상 한국어**로 쓴다. 코드, 식별자, 명령어, 오류 원문만 원래 언어로 둔다.

**Why:** 2026-10-01 세션에서 영어 리뷰 결과(pr-reviewer), GitHub API 출력, 영어 메모리 원문을 많이 읽은 뒤 답변이 두 번 연속 영어로 바뀌었다. 사용자가 "왜 갑자기 영어로", "왜 또 영어로"라고 지적했다. 한 번 사과한 직후 다시 반복해 신뢰를 잃었다.

**How to apply:** 영어 도구 출력이나 영어 서브에이전트 보고를 요약하거나 전달할 때 특히 주의한다. 답변을 보내기 전에 본문 언어가 한국어인지 확인한다. 서브에이전트 프롬프트에도 "보고는 한국어로"를 넣는다.
