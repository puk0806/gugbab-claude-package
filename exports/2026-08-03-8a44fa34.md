## 배경
relay 서버가 답변 스트리밍 종료 시 done 이벤트에 답변 요약을 실어주도록
확장할 예정이야: { "type": "done", "summary": "..." } (summary는 선택 필드).
소비 앱(health)은 이 요약을 저장해서 대화 이력 압축에 쓸 거야.

## 1. @gugbab/utils — SseEvent 타입 확장
- SseEvent 유니온의 done 변형에 선택 필드 추가:
  { type: "done"; summary?: string }
- parseSSELine / readSSEStream / toSSELine이 summary가 있어도/없어도
  그대로 통과시키는지 확인 (런타임 로직 변경은 없을 것으로 예상, 타입만)
- summary 없는 기존 done 이벤트와 100% 하위 호환이어야 함

## 2. @gugbab/hooks — useSSEChat onDone에 이벤트 전달
- 현재: done 수신 시 onDone?.() 으로 인자 없이 호출
- 변경: onDone?.(event) 로 done 이벤트 객체를 넘겨줘
  (소비자가 event.summary를 읽을 수 있게)
- 타입: onDone?: (event?: { type: "done"; summary?: string }) => void 형태로
  선택 인자로 만들어 기존 소비자( () => void )가 깨지지 않게
- 기존 chunk/error 동작은 변경 금지

## 3. 마무리
- 두 패키지 테스트 추가/갱신 (summary 있는 done, 없는 done 둘 다)
- 버전 올려서 npm publish (hooks가 utils 새 버전을 의존하도록)
